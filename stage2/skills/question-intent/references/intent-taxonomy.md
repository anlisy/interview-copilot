# Interview Question Intent Taxonomy

| intent | 核心问题 | 典型证据 |
|---|---|---|
| principle | 它是怎么工作的？ | 机制、流程、组件 |
| cause | 为什么会这样？ | 根因、触发条件、因果链 |
| solution | 怎么解决？ | 方案、步骤、组件 |
| optimization | 怎么做得更快/更稳/更省？ | 性能、成本、容量 |
| failure | 出问题怎么办？ | 故障、降级、恢复 |
| source | 底层怎么实现？ | 源码、调用链 |
| tradeoff | 为什么选 A 不选 B？ | 收益、代价、边界 |
| comparison | A/B 有什么区别？ | 对比维度 |
| design | 从约束设计系统 | 架构、接口、数据流 |
| verification | 怎么证明它有效？ | 测试、压测、指标 |
